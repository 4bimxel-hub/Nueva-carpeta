Sistema ECO v1

Evaluaciones Consultas Organizadas

Justificación

Permite organizar el registro, seguimiento y evaluación psicopedagógica y psicomotora de estudiantes.

Tecnologías

HTML5, CSS y JavaScript con almacenamiento local del navegador.

Conclusión

El sistema ECO v1 facilita la organización de información estudiantil, evaluaciones y reportes para apoyar el seguimiento de los estudiantes.

Gestión de docentes

Añade docentes, modifica sus datos, cambia contraseñas o bloquea/desbloquea su acceso.

Registro de accesos

Se muestra el usuario y la fecha/hora de cada inicio de sesión guardado en este navegador.

Aviso: esta versión guarda datos, cuentas e historial de accesos solo en este navegador. No sincroniza entre dispositivos y no es segura para uso real con datos sensibles: las contraseñas se guardan localmente. Para acceso compartido y auditoría fiable, conectar una base de datos en la nube con autenticación segura y permisos.
